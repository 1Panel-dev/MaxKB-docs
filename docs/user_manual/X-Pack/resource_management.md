# 资源管理

!!! Abstract ""
    资源管理功能为系统管理员提供统一、高效的资源可视化管理能力。系统管理员可以集中查看、管理和维护所有工作空间下的核心资源，包括 应用、知识库、工具、模型等。

## 1 资源查看
!!! Abstract ""

    支持查看不通工作空间的知识库、应用、模型、工具资源：

    - 资源展示：显示资源名称、类型、状态、工作空间、创建者、最近发布时间、创建时间等信息。
    - 搜索筛选：支持按创建者、名称、类型、状态、工作空间进行查询。

    支持关键词搜索和字段筛选，快速定位资源。

![资源](../../img/system/resource_management.png)

## 2 资源操作
!!! Abstract ""
    管理员可对不同类型资源执行特定操作，包括但不限于：

    - **应用**：支持去对话、管理、资源授权、导出、删除等；
    - **知识库**：支持管理、向量化、生成问题、配置设置、资源授权、导出为 Excel 或 ZIP、删除等；
    - **工具**：支持启/禁用工具、编辑、启动参数、资源授权、导出等；
    - **模型**：支持修改、资源授权、删除等；
