# 问题

!!! Abstract ""  
    MaxKB 知识库管理权限用户可以收集用户可能提出的相关问题，创建问题并关联知识库文档中的内容，维护知识库常见问题列表，以提高问答的准确度。
![问题列表](../../img/dataset/problem_list.png)

## 1 创建问题

!!! Abstract ""  
    点击【创建问题】，分行输入问题列表。
![创建问题](../../img/dataset/create_problem.png)

## 2 问题关联分段

!!! Abstract ""  
    点击【关联分段】，问题添加完成后，可以与文档中的分段进行关联，当用户提问时会优先匹配问题库来查询相关的分段。
![问题关联分段](../../img/dataset/problem_segmentation.png)

## 3 问题详情

!!! Abstract ""  
    点击【关联分段数】，可查看问题详情，可对分段内容进行修改或取消关联关系。

![问题详情](../../img/dataset/problem_detail.png)

## 4 删除问题

!!! Abstract "" 
    支持单个或批量删除问题，删除后关联分段中将不出现此问题。

![问题删除](../../img/dataset/problem_del.png)
